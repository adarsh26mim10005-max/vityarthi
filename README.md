# Train Ticket Booking System

A simple Python project for booking a train ticket.

## Features

* Enter passenger name
* Enter source city
* Enter destination
* Choose a train
* Display ticket fare
* Show booking details
* Confirm ticket booking

## Trains Available

1. Bhopal Express — ₹500
2. Shatabdi Express — ₹800
3. Rajdhani Express — ₹1000

## Technologies Used

* Python

## How to Run

1. Download or clone the project.
2. Open the Python file.
3. Run the program.
4. Enter the required details.
5. Select a train.
6. The booking details will be displayed.

## Concepts Used

* `input()`
* `print()`
* Variables
* `if-elif-else`
* Basic Python programming

